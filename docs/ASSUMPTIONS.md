# Current assumptions

- Customers, policies and evidence are synthetic; this is a hackathon app, not real lending.
- The brief permits alternate frameworks; React/Node/TypeScript implement its capabilities with PostgreSQL/pgvector.
- Authentication can be simulated; six accounts demonstrate four role boundaries.
- Banking verification tools can be mocked; live chat/embeddings use hosted providers.
- One local backend/database, local files and in-memory conversations are accepted demo limitations.
- Each recipient supplies keys and recreates data with seed/ingestion scripts.

See [guardrails](GUARDRAILS.md) and [schema](SCHEMA.md). Historical assumptions are preserved in the supporting-docs ZIP.
